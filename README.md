
# Lógica de Programação 🧠💻

Este repositório contém os arquivos desenvolvidos durante o curso de **Lógica de Programação** com foco em **JavaScript**. Os conteúdos abordam desde conceitos básicos até desafios práticos interativos com HTML, CSS e JS.

## 📁 Estrutura do Projeto

```
Logica-de-Programacao-main/
├── Primeiro curso/
│   ├── Curso 1/
│   │   ├── index.html
│   │   ├── style.css
│   │   ├── app.js
│   │   └── img/
│   └── exercicios/
│       ├── desafios.html
│       ├── desafios.css
│       ├── desafios.js
│       └── img/
```

### 🕹️ Curso 1

Projeto básico com interface gráfica para aprendizado da lógica com JavaScript. Inclui:

- HTML para estrutura
- CSS com design temático (robôs, troféus, fundo interativo)
- JavaScript com manipulação de lógica condicional e interação com o DOM

### 🧪 Exercícios

Desafios práticos voltados para fixação do conteúdo. Incluem:

- Interação com usuário via `prompt`/`alert`
- Condições (`if`, `else`, `switch`)
- Laços de repetição (`for`, `while`)
- Manipulação de elementos HTML com JavaScript

## 🚀 Como Executar

Você pode abrir os arquivos `.html` diretamente no navegador para testar as aplicações e interações.

Alternativamente:

```bash
git clone https://github.com/underthedarkxx/Python_Alura.git
cd Logica-de-Programacao-main/Primeiro\ curso/Curso\ 1
start index.html  # ou abra com seu navegador favorito
```

## 🎯 Objetivos

- Aprender os fundamentos da lógica de programação
- Aplicar conceitos de JavaScript na prática
- Desenvolver raciocínio computacional através de desafios
- Criar mini projetos interativos com HTML e CSS

## 🧠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
