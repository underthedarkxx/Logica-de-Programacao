## ⚙️ Setup do Ambiente

Siga este passo a passo para preparar o ambiente e executar os códigos:

1. **Clone o repositório**
   ```bash
   git clone https://github.com/underthedarkxx/Python_Alura.git
   cd Python_Alura
   ```

2. **Crie um ambiente virtual (recomendado)**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate      # Linux/macOS
   .venv\Scripts\activate       # Windows
   ```

3. **Instale dependências**
   Em cada pasta que tenha `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```

4. **Execute os arquivos**
   Navegue até a aula ou projeto desejado e rode o script principal:
   ```bash
   cd aula01_nome
   python main.py
   ```

### Aula 01 – Introdução
- Conceitos básicos da linguagem

- Condicionais (`if`, `elif`, `else`)
- Laços de repetição (`for`, `while`)
- Exercícios de fixação

### Aula 03 – Funções & Módulos
- Definição de funções
- Escopo e retorno
- Bibliotecas internas (ex.: `math`, `datetime`)

### Aula 04 – Estruturas de Dados
- Listas, tuplas, dicionários
- Iterações e manipulação de coleções
