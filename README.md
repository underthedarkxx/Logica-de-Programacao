# Lógica de Programação com JavaScript 🧠💻

Repositório com projetos, exercícios e desafios desenvolvidos durante o curso de **Lógica de Programação** utilizando **JavaScript**, **HTML** e **CSS**.

## ⚙️ Como Executar

Você pode abrir os arquivos `.html` diretamente no navegador para visualizar os projetos e desafios:

```bash
# Exemplo para abrir o projeto principal:
cd Logica-de-Programacao-main/Primeiro\ curso/Curso\ 1
start index.html  # ou apenas clique duas vezes no arquivo

```
